# AgentGuard Pricing

AgentGuard is **dual-licensed open core**. Everything you need to run in production is in the Apache 2.0 OSS build. You only pay when you want managed hosting, hosted threat-intel updates, or enterprise support.

## Open Core (Apache 2.0) — Free

- Full input/output/tool-call scanners
- LangChain + AutoGen integrations
- Python SDK + decorator
- Self-hosted Docker container
- Prometheus metrics + Grafana-ready
- YAML policy + hot reload
- Up to 1000-event in-memory audit log

**Self-host. No telemetry. Forever.**

## AgentGuard Cloud — From $49/mo per agent

For teams that want a managed control plane instead of running the proxy themselves:

- Managed proxy endpoint (multi-region)
- Hosted admin dashboard with multi-user RBAC
- Continuous threat-intel feed updates (denylists, new injection patterns)
- 90-day searchable audit log (SOC2-friendly)
- Slack / PagerDuty / webhook alerts on block events
- Auto-tuning policy recommendations
- Email support, 1 business-day SLA
